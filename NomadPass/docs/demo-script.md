# NomadPass Demo Script

## 3-Minute Flow

1. Connect Phantom or use the demo wallet fallback.
2. Upload a file named `passport.pdf`.
3. Show the agent trace: classification, privacy policy, encryption, issuer confidence.
4. Point to encrypted CID, credential PDA, NFT mint, and devnet proof fields.
5. Open the QR verification page.
6. Click revoke and show the verifier state changes.

## Judge Soundbite

NomadPass uses Solana as the neutral verification and permission layer. The document is encrypted and stored offchain; the chain stores credential state, proof commitments, NFT ownership, and sharing permissions.
